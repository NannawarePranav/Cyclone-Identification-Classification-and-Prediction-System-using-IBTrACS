# NOAA IBTrACS Raw Dataset Directory

This directory is intended to store the official raw NOAA IBTrACS v04r01 global dataset:
- File: `ibtracs.ALL.list.v04r01.csv` (~333 MB)

### Exclusion from Git
Because the raw CSV exceeds GitHub's 100 MB file size limit, it is excluded via `.gitignore`.

### Dataset Download
To download the original dataset:
- Direct Download URL: https://www.ncei.noaa.gov/data/international-best-track-archive-for-climate-stewardship-ibtracs/v04r01/access/csv/ibtracs.ALL.list.v04r01.csv
- Place the downloaded file directly into this directory (`raw/ibtracs.ALL.list.v04r01.csv`).
